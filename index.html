Início Projeto Funcionalidades

Alimentação inteligente para o seu animal

O PetFeeder é um projeto de um dispensador automático de comida para animais, desenvolvido para tornar a alimentação mais simples, prática e controlada.

Conhecer o projeto
🐶

Sobre o projeto

Este projeto tem como objetivo desenvolver um sistema capaz de dispensar automaticamente uma quantidade definida de comida para animais em horários programados.

⏰

Alimentação programada

Permite definir horários para a distribuição automática da comida.

⚙️

Automático

O sistema funciona de forma autónoma, reduzindo a necessidade de intervenção manual.

🐱

Para animais

Pensado para facilitar a alimentação diária de cães, gatos e outros animais domésticos.

Funcionalidades

O dispensador poderá integrar diferentes funcionalidades para tornar o processo de alimentação mais eficiente.

🍖

Dosagem de comida

Distribuição de uma quantidade controlada de alimento.

📱

Controlo

Possibilidade de acompanhar e controlar o sistema através de uma interface.

🔋

Eficiência

Projeto pensado para funcionar de forma prática e eficiente no dia a dia.
